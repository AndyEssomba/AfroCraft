# AfroCraft

AfroCraft is a browser-based 3D voxel game inspired by Minecraft, set in an African universe. Built with Three.js and Vite (no backend, no server), it runs entirely client-side.

Explore a procedurally generated 128×128 world with three biomes — savanna, desert, and tropical forest — break and place blocks, and experience a full day/night cycle.

Gameplay includes first-person movement with gravity, collisions, and swimming. The MVP includes nine block types, including red earth, baobab wood, and clay, and targets 60 FPS on integrated graphics in modern Chrome and Firefox.
