# Règles de travail — AfroCraft

## Portée des tâches

- Implémenter **uniquement** la tâche demandée. Ne pas élargir le périmètre, ne pas ajouter de fonctionnalités, d'abstractions ou de code défensif au-delà de ce que la tâche exige.
- Ne pas refactoriser le reste du code. Laisser intact le code qui n'est pas directement concerné par la tâche en cours.

## Vérification

- Lancer `npm test` à la fin de chaque tâche et s'assurer que tous les tests passent avant de considérer la tâche terminée.
- Corriger les erreurs révélées par les tests avant de présenter le résultat.
